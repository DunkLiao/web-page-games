# 網頁遊戲集合 (Web Page Games Collection)

## 📌 項目簡介

這是一個包含多個網頁小遊戲的集合項目。所有遊戲均採用 HTML5, CSS3 (Tailwind CSS) 與 Vanilla JavaScript 開發，無需複雜框架，支援電腦和行動裝置觸控，提供流暢、高互動的沉浸式遊玩體驗。本項目目前已收錄 **30 款** 精緻的小遊戲！

---

## 🎮 遊戲列表

### 1. 貓與鼠：藝術大冒險 (Catch Cat Games)
- **文件**: `CatchCatGames.html`
- **描述**: 在靜謐的草坪上展開追逐冒險。操控貓咪捕捉老鼠，收集分數。
- **技術**: HTML5 Canvas, Tailwind CSS

## 🚀 快速開始

1. **本地遊玩**: 直接雙擊在瀏覽器中開啟 `index.html` 即可。
2. **適配瀏覽器**: 支援 Chrome, Safari, Edge, Firefox 等主流現代瀏覽器。
3. **行動裝置**: 介面均適配手機版，支援多點觸控與按鈕操作。
